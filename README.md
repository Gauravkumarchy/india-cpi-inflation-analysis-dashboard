# India CPI Inflation Analysis & MIS Dashboard

## Overview

This project analyzes India's Consumer Price Index (CPI) data from **2019 to 2023** using Microsoft Excel. Raw CPI data was transformed into structured reports and an interactive MIS dashboard was created to track inflation trends, compare CPI categories, and identify the major categories associated with changes in overall inflation.

The dashboard is designed as a ready-to-use Excel report: download the workbook, open it in Excel, and explore the available analysis and visualizations directly from the dashboard.

## Objective

The main objective of this project is to understand how different CPI categories contributed to India's inflation trend during the period from 2019 to 2023.

The analysis focuses on:

- Monitoring overall CPI inflation trends over time.
- Comparing inflation movement across major CPI categories.
- Identifying categories that contributed most to inflation increases.
- Understanding the relationship between category-level CPI movements and overall inflation.
- Converting raw data into structured MIS reports for accurate reporting.
- Presenting insights through an executive-friendly Excel dashboard.

## Dashboard Highlights

The Excel dashboard provides a consolidated view of:

- Overall CPI inflation trends from 2019 to 2023.
- Category-wise inflation performance.
- Monthly and yearly trend comparisons.
- Contribution of major CPI categories to inflation movement.
- Identification of critical categories associated with higher inflation.
- KPI summaries and visual trend analysis.
- Structured MIS reporting for business and management review.

## CPI Categories Covered

The analysis combines and compares the available CPI categories, including major groups such as:

- Food and beverages
- Housing
- Fuel and light
- Clothing and footwear
- Pan, tobacco and intoxicants
- Miscellaneous

> Category availability and grouping may vary based on the source dataset and the structure used in the Excel workbook.

## Key Analysis Approach

1. Collected and reviewed CPI data covering 2019–2023.
2. Cleaned and structured the raw data for analysis.
3. Consolidated CPI category data into a reporting-friendly format.
4. Created monthly and yearly trend views.
5. Compared category-level movements with overall CPI inflation.
6. Identified critical categories associated with inflation increases.
7. Built an Excel MIS dashboard to present the results clearly.

## Insights Delivered

The dashboard helps users answer questions such as:

- How did India's CPI inflation change between 2019 and 2023?
- Which CPI categories experienced the strongest increases?
- Which categories were most closely associated with changes in overall inflation?
- Were inflation movements consistent across all categories?
- Which categories should be monitored closely during periods of rising inflation?

The analysis identifies relationships and patterns between CPI categories and overall inflation. These relationships should be interpreted as analytical associations rather than proof that one category alone caused the change in inflation.

## How to Use the Dashboard

1. Download [`India_CPI_Inflation_Analysis_Dashboard.xlsx`](./India_CPI_Inflation_Analysis_Dashboard.xlsx).
2. Open the workbook in Microsoft Excel.
3. Navigate to the dashboard and report sheets.
4. Review the KPI summaries, charts, category comparisons, and inflation trends.
5. Use the workbook's filters or interactive controls, where available, to explore the data.

For the best experience, open the workbook in the desktop version of Microsoft Excel with formulas, charts, and interactive dashboard features enabled.
